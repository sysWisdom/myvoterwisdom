What is this about?

Imagine you're a teacher grading a student's answers to a test. This report is like the grading system for a computer program that tried to guess the correct answers to a set of questions.

What do the numbers mean?

Precision: How many of the answers the computer guessed correctly out of all the answers it gave? (Think of it like the percentage of correct answers it actually got right from what it claimed was right.)

Recall: Out of all the correct answers that existed, how many did the computer find? (Like finding all your missing socks – did the computer find them all or just a few?)

F1-Score: A balance between precision and recall. If precision is like accuracy and recall is like effort, the F1-score shows how well they worked together.

Support: How many questions were in each group or category that the computer was grading.
