About this project

🏛️
Public data only

County-level election records 2004–2024. No PII. No voter targeting.

🔬
4 ML models

Random Forest · Logistic Regression · SVM · Gradient Boosting with SMOTE balancing

⚖️
Non-partisan

Educational research only. Not for use in campaigns or political advertising.

Data sources: 39 hand-curated counties (Tier 1, includes registration + mail-in data) combined with MEDSL / Harvard Dataverse presidential returns (Tier 2, CC BY 4.0) for 1,956 counties total. The original 39 counties were selected pragmatically for Wisdom Formula validation — not as a statistically representative sample. The global model now draws on cross-county patterns from all 1,956 counties. See full methodology →
